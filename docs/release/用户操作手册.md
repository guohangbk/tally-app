# Tally 塔莉 · 用户操作手册

| 项目 | 内容 |
|---|---|
| 文档版本 | v1.0 |
| 日期 | 2026-11-01 |
| 适用版本 | 当前主仓 HEAD（`0.1.1-dev` 起的形态）；正式版号只出现在发布提交上，App 内「设置 → 关于 → 版本」显示的就是你手上那个包的 `versionName (versionCode)` |
| 运行环境 | Android 9 及以上，手机本地存储，无需登录、无需联网 |

## 0. 三分钟上手

1. 第一次打开会让你选一条路：**导入历史账单**、**导入 Tally 备份**，或**直接从零开始**。后两条都会自动建好「日常账本」和一套默认分类。
2. 屏幕底部正中的 **＋** 就是记账。点一下打开记账页，输金额、选分类、按「保存」。
3. 想连着记：**按「再记」**，金额清空、分类留着，直接记下一笔，不用退出重来。
4. 想看这个月花在哪：点顶部右侧的**柱状图标**进统计。
5. 想换账本：点顶部的**账本名字**。所有管理入口都在左上角的**抽屉**里。
6. 想把 App 放到桌面上：长按桌面空白处 →「小组件」→ 找 Tally。有八种可选（近七日、收支速览、快速记账、预算环、消费节奏、连续记账），都是只读的。

## 1. 记一笔

| 操作 | 怎么做 |
|---|---|
| 新增 | 点 **＋** → 选支出/收入 → 选分类 → 输金额 → 保存 |
| 连记 | 保存行左侧的**再记**：清金额留分类，页面不跳走 |
| 算账 | 键盘上的 **−** 和 **＋** 进入算式（例：`18 + 12`），**保存**就是等号；结果为负会提示并禁止保存 |
| 清空 | 长按 **⌫** 一次清掉金额与算式 |
| 改日期 / 备注 | 金额下方的日期与备注行，直接点 |
| 标记报销 | 支出账单可打「报销」标记（需先在设置里开启报销功能） |
| 不计入收支 | 打「排除」标记，这笔不再进任何金额汇总，但仍出现在列表与笔数里 |
| 附凭证 | 开启「账单图片」后，记账页出现「图片」，可选图并自动压缩 |
| 改一笔 | 在账单上点一下 → 底部卡片 → **修改**（会带着原数据回到记账页） |
| 删一笔 | 底部卡片 → **删除** → 确认；删完弹层就关，**去回收站找** |

## 2. 看账

- **首页**：顶部是月份与本月汇总（支出、收入、笔数、日均、结余），下面按天列出账单。
- **翻月**：点月份两侧的箭头一次走一格；点月份文字直接开年月选择器，可以跳到任意年月。
- **批量**：**长按**任意一行进入勾选，底部出现动作条，可一次删除、改分类或打标记（第二排还有改日期 / 改备注 / 移至账本）；按返回先退出勾选。
- **搜索**：顶部放大镜。默认只摊开关键词与收支类型，其余条件（时间、账本、来源、排序、金额区间）收在**更多筛选**里；收起时已生效的条件会写在开关下面，结果里可直接全选做批量。

## 3. 统计

- 顶部切**月 / 年**，页面分四段：收支总览、分类报表、排行、趋势。
- 分类报表可折叠展开；点饼图或图例会联动到该分类明细；合并的小类点开看明细。
- 「支出视图剔除未报销」打开后，待报销的支出暂不计入支出合计。
- 统计看的是**首页当前所选的账本**：首页顶栏切到「全部账本」或某一本书，进来就是那个范围；统计页自己不换账本。
- 想看每个数字怎么算出来的：**设置 → 使用指南**，最后一段「统计口径」逐条写着计入、冲抵还是剔除。
- 配好小莉后，统计页右下角会出现一颗分析胶囊，**点一下才算**，不点不产生任何请求。

## 4. 账本与分类

| 想做的事 | 位置 |
|---|---|
| 新建 / 改名 / 归档 / 删除账本 | 抽屉 → 我的账本 |
| 设为默认 | 我的账本，点账本左侧圆圈（默认账本不能删也不能归档） |
| 切换当前账本 | 顶部账本名字 |
| 新增一级分类 | 抽屉 → 分类管理 → 右上角 ＋ |
| 新增二级分类 | 一级卡片上的「添加二级」，可一次连建多个 |
| 改名或换图标 | 分类卡片右上角 **⋯** → 修改（全屏页，填好名称选图标） |
| 调整顺序 | 长按卡片拖动，松手插到金线位置 |
| 归档 / 恢复 | 分类的 **⋯** 菜单；已归档分类在页面底部「已归档分类」区 |
| 删除分类 | **⋯** → 删除；有账单的分类必须先选一个去处（提示的笔数是**全部账本**的合计） |

分类是**全机共用**的：新建账本不需要重配分类。

## 5. 周期、分期、报销

- **周期记账**（抽屉 → 周期记账）：设一次，到期自动补记。支持每日 / 每周 / 每月 / 每年 / 每月最后一天；可设结束日期或期数。错过的日子会在下次打开时补记，**账单日期仍是应执行日**。列表里每条都写着所属账本。
- **分期管理**：把大额支出拆成多期，可选手续费并入每期或单独成期，末期自动校正分币尾差。可「提前结清」，已生成的账单保留。
- **报销管理**：把支出标为待报销，报销后一次确认转「已报销」并可撤销。这里只改状态、**不动账单金额**；但已报销那几笔不再计入本月支出，待报销照常计入。长按任意一行进入选择态，行尾多出「确认」可以一笔一笔地报。

## 6. 导入、导出、备份

| 场景 | 步骤 |
|---|---|
| 从别家 App 迁移 | 抽屉 → 设置 → 数据 → **导入账单** → 选来源（模板 / 钱迹 / 支付宝）→ 选文件 → 看预览与异常行 → 选目标账本 → 导入 → 看对账报告 |
| 用我们的模板 | 导入页可先「下载模板」（12 列 CSV，写到 下载/Tally） |
| 导出数据 | 设置 → 数据 → **导出账单** → 选时间范围、账本、CSV/XLSX → 导出（13 列，落在 下载/Tally，可直接再导入） |
| 换手机 | 旧机：设置 → 备份与同步 → 生成备份（可勾选包含图片，设密码）→ 把 `.tally` 拷到新机 → 新机首次打开时选**导入 Tally 备份**，或设置 → 备份与同步 → 恢复 |
| 云端留一份 | 备份页可填 WebDAV 地址，**手动**上传与下载；App 不会后台偷偷同步 |

**备份不包含**：小莉的 API Key、WebDAV 密码、App 偏好设置（主题、开关等）。恢复后需要重新填 Key 并测试；没勾选包含图片时，图片位置会显示「图片未包含在备份中」。

## 7. 小莉（可选）

1. 开启：设置 → 小莉（AI）→ 打开开关。不开也完全不影响记账。
2. 配置：设置 → **小莉配置** → 选服务商（OpenAI / DeepSeek / 智谱 / 千问 / 自定义）→ 选模型 → 决定是否勾选「支持图片输入」→ 填 API Key → 勾隐私告知 → **测试并保存**。测试不过什么都不会保存。
3. 使用：**长按 ＋**，向右滑进入小莉对话。直接打字、点话筒说话（再点一次结束）、或点图片按钮发截图（最多 3 张）。
4. 记账：小莉把一句话或一张截图认成几笔后会给你一张卡，逐笔点「记入」才会写账；不想记的点「先不记」，它会划掉留痕，可恢复。
5. 删除对话：点标题打开会话列表，可重命名或删除。删除只影响对话文字，不影响已记入的账单。

**注意**：只有你主动发送的内容会离开手机。账单库、未发送的历史消息、图片原文件都不会上传。

## 8. 语音与截图

- **语音**：长按 ＋ 向上滑，或在小莉对话里点话筒。说完再点一次结束。识别结果只填进输入框，你确认后才会记账。
- **截图**：长按 ＋ 向左滑从相册选；或在相册里点「系统分享 → 塔莉」；首页也支持一次选多张（最多 9 张）。识别在本机完成，不联网；识别不出来的字段留空让你补，低置信度的那一行会标红，选完才能保存。

## 9. 设置项速查

| 设置 | 默认 | 作用 |
|---|---|---|
| 账单图片 | 关 | 记账页是否显示图片入口 |
| 报销 | 关 | 是否出现报销字段与报销管理 |
| 账单时间精度 | 精确到日 | 账单分组与统计粒度，可改为到时和分 |
| 小莉（AI） | 关 | 全站 AI 入口的唯一开关 |
| 主题 | 跟随系统 | 浅色 / 深色 / 跟随系统 |
| 货币符号、千分位 | 开 | 金额显示 |
| 导入 / 导出 / 备份与同步 / 小莉配置 | — | 数据与 AI 入口 |
| 导出诊断包 | — | 一键生成一份排障文本（版本、机型、日志尾巴），**不含任何一笔账的内容**；落「下载」目录并直接弹系统分享 |
| 恢复默认 | — | 只重置偏好，不动账单 |

## 10. 关于

设置页最下面那一段：

| 一行 | 说明 |
|---|---|
| 版本 | 显示的是**这个包自己的** `versionName (versionCode)`，跟着构建变，不是写死的一串 |
| 项目主页 | 点开用浏览器进 `tally.guohang.asia`，下载与文档都在那儿；没装浏览器会提示一句，不影响用 App |
| 数据包名 | 普通的一行信息；1.2 秒内连点 5 次会切换调试模式（开了才出应用内调试台） |
| 使用指南 | 「怎么用」与「每个数字按什么口径算」 |
| 许可与依赖 | BUSL-1.1（源码可用，不是开源）与第三方依赖清单 |

## 11. 常见问题

| 问题 | 处理 |
|---|---|
| 删错了 | 删除是软删，弹层当场关掉，找回走 **设置 → 数据 → 回收站**，保留期内可单条或整组恢复，到期才物理删除 |
| 统计数字对不上 | 先看是否有「不计入收支」的账单，再看是否开了「剔除未报销」，最后对照 **设置 → 使用指南 → 统计口径** |
| 换机后小莉用不了 | 备份不含 Key，需重新填写并测试 |
| 语音没反应 | 检查麦克风权限；部分机型系统引擎不可用，可改用打字 |
| 升级后数据没了 | 库版本一直是 1、**不走迁移**：改了表结构之后，设备上那份旧库与新手上的包对不上，App 打开就会报错停住（**不会清库**）。解法是先用 **设置 → 数据 → 备份与同步** 里的 `.tally` 包恢复，或卸载重装后导入备份 |
| 想把问题反馈给作者 | 设置 → 数据 → **导出诊断包**：点一下生成一份文本，落在「下载」目录并弹出系统分享。里面有版本、机型、各表的**记录条数**和日志尾巴，但**没有任何一笔账的金额、备注、分类名或账本名**，可以放心发 |
| 想彻底清空 | 设置 → 恢复默认只重置偏好；账单数据请通过删除或覆盖式恢复处理 |
