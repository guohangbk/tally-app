## 1. 设计语言

纸墨基调 + 一处金晕。整面屏幕只允许小莉相关触点使用金色光晕（入口、建议、气泡、光晕环），其余保持纸墨，避免「哪里都在发光」。

| 色板 token | 用途 |
|---|---|
| `paper` / `card` | 纸面背景 / 卡片面 |
| `ink` / `ink2` / `ink3` | 主文 / 次文 / 辅助文（灰字只用于说明，不用于正文） |
| `line` | 1dp 分隔与描边 |
| `brand` / `onBrand` / `brandSurface` | 墨绿品牌色：主操作与选中态 |
| `expense` / `expenseSurface` | 陶土：支出、错误、危险操作 |
| `income` | 收入 |
| `slate` | 灰蓝：已归档、被排除、次要标签 |
| `gold` / `goldHi` / `glow` / `onGlow` | 香槟金：只给小莉 |
| `summaryBar` / `onSummaryBar` | 首页月度汇总条的深色渐变 |
| `disabledAlpha = 0.4f` | 禁用态统一透明度 |

主题：`ThemeMode.SYSTEM` / 亮 / 暗，`tallyColors.isDark` 驱动同一套 token 换值，不另建暗色组件。

## 4. 导航与页面形态

- 首页常驻，**没有底部 tab**。顶栏四个触点：抽屉、标题（切账本）、统计、搜索。
- `＋` 是唯一记账入口：短按进记账页；长按展开扇形——上＝语音、左＝截图、右＝小莉。右臂不随开关消失：小莉关闭时右滑落到设置里的开关区，开启未配置落到配置页，可用才进对话页。扇形只用上、左、右三个方向。
- 抽屉分两组：管理（账本 / 分类 / 报销 / 周期 / 分期）与系统（设置 · 关于）；内容避开状态栏；从抽屉进的二级页返回时回到抽屉。
- 账单详情是**底部弹窗**，不提供详情页，也不在弹窗里就地编辑——要改就跳记账页。
- 弹层里的长列表给上限高度 + 内部滚动（正文最高 360dp，用 `Modifier.sheetBody()`），不顶满整屏；顶部只留 M3 默认那一条抓手，不再另画一根。
- 只由系统分享触发的页面（截图记账）不出现在应用内导航里。

## 5. 交互约定

### 5.1 提示语预算

每屏最多一条灰色说明。要解释的东西写进设计板批注，不摊到界面里。散落的小灰字不在界面里出现。

### 5.2 反馈形式

| 场景 | 用什么 | 不用什么 |
|---|---|---|
| 操作完成 / 失败的一次性提示 | `TallyToast`（贴底、自动收起） | 顶部横幅 |
| 弹窗内容态、卡片内错误态、引导页阻塞态 | `TallyErrorBanner` / 卡片内文案 | — |
| 破坏性动作 | `TallyConfirmDialog` | 直接执行 |
| 找回 | 回收站页面 | 常驻提示条、反悔气泡 |
| 页上有弹窗时 | 弹窗自己承担错误 | 页面级气泡接手同一条 error |

一次性结果的气泡按语气定长（成功 3 秒 / 中性 2.4 秒 / 警示 4.2 秒），不靠撑长兜命。

### 5.3 状态可见性

- 选中态不能只靠颜色：加勾、加描边或加左侧色条（批量选择是 3dp 品牌色左边线 + 半透明底）。
- 触摸目标 ≥ 48dp（视觉上可以只是一个小图标，触摸框按 48dp 撑开）。
- 「进入 / 选择 / 下载」这类尾部文字统一换成 chevron 或下载字形，且一次改全站。
- 被排除的账单整行降到 0.55 alpha 并保留划线文案，不直接消失。
- 上限要说出口：达到上限时禁用并说明原因，而不是让控件消失或静默截断。

### 5.4 记账页

- 键盘 4×4 十六格等宽等高（键高 42dp），`+/−` 进入算式态、保存即等号。
- 二级分类多行平铺，不缩进、不开新页；默认图标按二级各自独立，不再继承父级。
- 输入法弹出时不整页顶起，也不挪动键盘位置。
- 卡片上的「查看统计」跳到已按条件筛好的搜索页，而不是裸统计页。

### 5.5 分类管理页

- 一级卡片 + 密集 5 格二级平铺，**不做缩进树**。
- 操作弹层只列动作（修改 / 看数据 / 加二级 / 排序 / 归档 / 删除），「修改」打开预填好的全屏页，不在弹层里改。
- 笔数与删除文案一律按**全部账本**口径。
- 归档区在页面底部，可展开、可恢复；只有 0 笔的分类能彻底删除。

### 5.6 小莉

- 卡片只由 `propose_bills` / `not_a_bill` 两个工具产出，一次调用交一批；卡片落默认账本，点「记入」才写库。
- 语音是点击开关：点一下开始录，再点结束并发送，说满 20 秒自己收尾。
- 一条消息最多 3 张图；待发图在输入框上方展开，可点开看大图、可逐张移除。
- 「先不记」= 划掉保留，不删气泡；新建对话不复用空会话。
- 配置页保存成功后收起表单，只留当前配置卡；界面不显示「已就绪 / 在线」这类状态标签和状态点。

## 6. 新增交互判据

| 判据 | 定稿 |
|---|---|
| 能兑现才承诺 | 系统能力不可控时，界面只承诺验证过的部分：提醒说「今天之内」不说「20:00 整」；组件里不放写库按钮；快捷方式不承诺厂商一定照排。 |
| 口径先于界面 | 退款冲抵、月起止日、预算四个新数字先进口径表再上界面；边界计算只有 `domain/Period.kt` 一个出口。 |
| 找回走页面 | 软删之后找回只走回收站，删除不挂反悔气泡；一次性结果的气泡按语气定长，不靠撑长兜命。 |
| 提醒不喧哗 | 四类通知各自可关；同一对象同一周期段只发一次；预算超支在页面上不出现常驻红字，进度条转陶土即为表达。 |
| 伪交付零容忍 | 列、开关、方法存在但界面上碰不到，一律按缺陷处理：要么补出入口，要么删干净，不留「看起来有」的东西。 |
| 复用不新造 | 选图标复用 `IconLibraryPage`；预算金额输入复用 4×4 键盘；图片查看器与对话待发图共用组件不共用状态；弹层一律 `TallyConfirmDialog` / `Sheet` 那套。 |
| 上限要说出口 | 一次批量截图 9 张、一条对话消息 3 张图、搜索结果 1000 笔、口令 4 位起——达到上限时禁用并说明原因，而不是让控件消失或静默截断。凭证图一笔一张，没有「再加一张」的入口。 |
| 金晕边界不变 | 金色仍只给小莉。预算阈值使用金色**仅限**「机器建议你去点什么」的场合，普通提醒用墨绿与陶土。 |
| 提示语预算不变 | 每屏 ≤ 1 条灰字；每屏的批注写在设计图里，不摊到界面上。 |

## 7. 震动反馈（`TallyHaptics`）

| 方法 | 系统常量 | 用在 |
|---|---|---|
| `tap()` | `CONTEXT_CLICK` | 卡片、按钮、开关、分段选择、列表行、账单行点击、抽屉入口、切账本 |
| `key()` | `KEYBOARD_TAP` | 记账键盘数字与运算符 |
| `longPress()` | `LONG_PRESS` | 长按账单行、`＋` 扇形展开、长按键盘键 |
| `confirm()` | `CONFIRM`（API 30+，否则回退 `CONTEXT_CLICK`） | 保存账单、扇形松手落到某个入口 |
| `reject()` | `REJECT`（API 30+，否则回退 `LONG_PRESS`） | 取消/删除类动作 |

全部走 `View.performHapticFeedback`，不需要 `VIBRATE` 权限，自动跟随系统「触感反馈」开关；视图未 attach 时静默跳过。

## 8. 动效

- 弹层、待发图条、折叠区用 `AnimatedVisibility` + 180ms 级展开/收缩；展开与收起不对称（收起更快），避免「收得不情不愿」。
- 页面转场统一由导航层给，单页不自定义。
- 小莉的呼吸动效只有一处语言：`AiBloom` 三层同心环 + 茉莉花形，聆听中与分析载入中复用。

### 当场可按的验收

| 按什么 | 应看到什么 |
|---|---|
| 旧包覆盖安装 | 从 v0.1.5 覆盖安装 0.1.6 时自动执行 `MIGRATION_1_2`（只建标签两表），首页汇总与统计四段数字与升级前一致；真对不上时报错停住、**不清库**。 |
| 同一份账单导两次 | 重复行单独成一段并默认跳过，判重键写明是外部 ID 还是组合指纹。 |
| 说一句「二十九块八毛五」 | 金额 29.85、备注不是整句话；开着小莉说同一句，金额不被改写。 |
| 退 60 再退 138 | 第三笔被拦，原单累计「已退 ¥198」；退款按原单分类冲抵。 |
| 删一笔再看回收站 | 确认弹窗说清后果，删完不挂反悔气泡；回收站按删除日分组，恢复回到原账本原位，图片一并带回；彻底删除报出笔数与释放量。 |
| 超期与失败的任务 | 当天无账单只来一条、点它进记账页；失败聚合成一条，同一规则同一周期段不重发。 |
| 搜索加金额区间与排序 | 列表、合计、四条排序同一口径；超过 1000 笔在末行明说还剩多少。 |
| 统计选一段区间 | 四段全部按该区间重算；只有一个桶时不画折线；点某天 / 点二级都走同一个下钻弹层。 |
| 批量改日期 · 改备注 · 移账本 | 幂等冲突（周期 / 分期的期次）整批跳过并列出来，不静默跳过；结果气泡给出笔数与合计。 |
| 预算到 80% 与超支 | 当日一条通知、同段不重发；页面上进度条转陶土即表达，不常驻红字；点 ＋ 撞上同段预算直接进那条编辑。 |
| 桌面 | **八枚**组件都只读（近七日 / 收支速览 2×2、4×2 / 快速记账 2×2、4×2 / 预算环 / 消费节奏 / 连续记账），长按图标只有「记一笔」与「查看统计」两条；取数失败显示「—」并标「未更新」，绝不显示 ¥0.00 冒充。 |
| 海报开脱敏 | 金额、笔数、口令句里的数字全部隐去，比例条与排序保留；分享不落相册，保存两次仍只有一个文件。 |
| 备份口令 | 4 位起、允许字母；提示说清「只提下限，不锁旧包」。 |
| 全仓搜「账户 / 余额 / 同步 / 多端」 | 无功能命中——产品定位没有漂。 |

### 两条硬流程

**改了实体**：`version` 一直是 1、没有迁移链，所以第一项不是「覆盖安装后数据还在」而是「**报错停住、不清库**」——先导出 `.tally` 备份，重建后再核对首页汇总与统计页四段的数字没变；`fallbackToDestructiveMigration` 不配。

**改了口径**：先写进口径表，再上界面；同一段边界在领域层只有一个出口。
